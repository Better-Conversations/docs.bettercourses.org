# Commit Style

- Write concise commit messages that explain the "why" not just the "what"
- Reference issue IDs where relevant: `Fix flight plan links (BCTT-738)`
- Use multiple commits for logically separate changes — don't force everything into one
- Always include `Co-Authored-By: Claude Opus 4.6 <noreply@anthropic.com>` when Claude contributes
- When creating PRs, include a summary of changes and test plan
