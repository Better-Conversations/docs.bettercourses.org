# Pattern Documentation Rules

- Pattern pages follow the template at `source/documentation/patterns/pattern-template.rst`
- Patterns and guidance notes are separate sections but should cross-reference each other
- A pattern can reference a guidance note for detailed steps, and vice versa
- Focus on `patterns/core-delivery/` — the 4 empty categories (roles, exercises, timing, visual-technical) are deferred until there is clear demand
- Use `.. todo::` directives to mark planned work, referencing Linear issue IDs (e.g., `BCOBS-1126: Co-facilitation pattern`)
